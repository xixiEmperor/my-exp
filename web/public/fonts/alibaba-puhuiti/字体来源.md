# 阿里巴巴普惠体字体来源

本目录使用阿里巴巴普惠体 3.0，保留官方发布的 WOFF2 文件内容，仅简化本地文件名。

| 本地文件 | 官方字重 |
| --- | --- |
| AlibabaPuHuiTi-Regular.woff2 | AlibabaPuHuiTi-3-55-Regular |
| AlibabaPuHuiTi-Medium.woff2 | AlibabaPuHuiTi-3-65-Medium |
| AlibabaPuHuiTi-Bold.woff2 | AlibabaPuHuiTi-3-85-Bold |

字体来自[阿里巴巴普惠体官网](https://www.alibabafonts.com/)，资源由官网引用的 `fonts.alibabadesign.com` 提供。

使用范围以官网提供的[法律声明](https://www.yuque.com/yiguang-wkqc2/hgpff0/nus9wiinq4aeiegy)为准。本说明用于记录文件来源，不替代官方声明。

打开 `demo.html` 时，请保留整个 `demo-assets` 文件夹。字体在本地加载，无需连接第三方字体服务。
